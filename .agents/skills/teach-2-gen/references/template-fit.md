# 教学主体图的尺寸与模板适配

## 验收模式

- **用户已选择PPT模板：默认按模板适配验收。** 图片完整放入模板后，横向按确认区域放置，等比缩放、水平居中、底端与幻灯片底端对齐，顶部低于模板横线下沿及必要安全间隙，不能遮挡横线、标题或页号。像素尺寸是生成参考和记录信息，不能代替实际排版验收。
- **用户明确坚持精确像素：按指定宽高逐像素检查。** 不因模板适配通过而静默放宽。工具不能达到要求时先实测、报告限制，等待用户决定；不得用未授权后处理冒充直接生成。
- **模板未确定：** 可先规划、写提示词；已有生图授权时也可生成并核对内容，状态分别记“内容已核对／模板适配未验证”，不能把缺模板当作整套生图自动停止的理由，也不能宣称模板适配通过。需要据模板验收时，沿用当前聊天已确认模板；只有缺失或冲突才询问，不自动选用共享模板或旧成品。

1814×867、1824×864等尺寸不是跨用户硬性标准。每个模板的横线高度、标题区、幻灯片比例和可用宽度可能不同；不能把某人的模板坐标、比例、安全间隙或允许的后处理写死为所有任务要求。实际尺寸始终如实记录。

## 读取模板与计算

1. 读取用户选定模板及适用页的幻灯片宽高、主体区宽度、标题和横线。优先读取原生对象及其版式/母版关系；横线可能位于页面、布局、母版、背景图片或组合内，计算时包含线宽和组合变换。
2. 同时渲染模板。横线无法从对象可靠定位时，可结合图像线条检测、必要OCR和目视核对定位；OCR适合辅助辨认文字/区域，不能单独证明细横线边界或没有遮挡。未可靠定位前不得把猜测坐标写成已验证。
3. 横线保护下沿记为 `Y_line_bottom`，下方安全间隙记为 `g`，页高为 `H_slide`。主体安全高度为 `H_safe = H_slide - Y_line_bottom - g`。没有横线时，使用已确认页眉下安全区域，不凭空添加横线。
4. 图片真实宽高为 `w_px, h_px`，包括完整白色画布。目标横向区域宽为 `W_target`。先计算满宽等比高度 `H_full = W_target × h_px / w_px`，底端对齐后的顶部为 `Y_top = H_slide - H_full`。
5. 若 `Y_top >= Y_line_bottom + g`，按目标宽度等比放置，保留顶部小间隙。若满宽时过高，使用 `s = min(W_target / w_px, H_safe / h_px)` 等比缩小，水平居中、底端对齐；记录缩小后的宽度和横向间隙，检查课堂可读性。用户坚持满宽且比例不能兼容时报告几何冲突，不变形凑齐。

不要只看图片内主体是否碰线：整张白色图片即使白边没有文字，也会覆盖下方模板横线。不得让图片的整幅边界越过保护区。

## 原图和后处理

默认保留生成PNG，优先通过PPT中的等比缩放完成适配，不为1～2像素的差异重采样或反复生图。不得裁掉教学内容，不同时强设图片宽高形成拉伸，也不通过上下补白解决过高问题。

用户在本任务明确允许横向补白、宽度微缩或等比微调高度时，可按其具体授权执行；不得将仅宽度微缩谎称为全程等比。记录原图和处理后图片的尺寸、哈希、处理方法与放置参数，保留原图。其他用户/任务不得自动继承这类后处理许可。

## 真实验收与传播

整套生成先拿首张真实图片进行模板试排，实际渲染确认横线、标题区、完整主体、底边和可读性，再继续。后续各图按实际比例核对并检查试排渲染；不能以首张或结构校验通过代替所有页面验收。尺寸适配检查是生成阶段的质量核对，不自动授权交付整套嵌图PPT或可编辑复现。

唯一索引记录真实尺寸、最终图哈希及状态；生成记录保存模板路径/版本哈希、横线定位依据、图片位置/缩放/间隙、试排和渲染结论。复现交接引用这些证据，第四阶段沿用本次模板安全区域。换模板后重新计算并验证，旧模板适配结论不能直接沿用。
