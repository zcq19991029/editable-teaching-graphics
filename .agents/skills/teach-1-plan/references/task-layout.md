# 教学图任务目录（必须执行）

任务文件夹确定后，生成到哪一类材料就创建对应子目录，不预建空目录。以下是文件存放要求，不是可选目录示例：

| 文件 | 必须存放位置 |
| --- | --- |
| 当前逐图完整提示词 | 提示词/P01-确认标题-提示词.md |
| 最终选定教学图片 | 图片/P01-确认标题.png（或真实jpg扩展名） |
| 逐图复现清单 | 复现清单/P01-确认标题-复现清单.md |
| 输入PPT等原始资料 | 输入/ |
| 本任务静态参考素材 | 参考素材/ |
| 预览、试排、运行中间文件与失败诊断 | 临时/ |
| 唯一索引、规划、生成记录、复现交接 | 任务根目录 |
| 合成展示版PPTX | 任务根目录/任务名-嵌图版.pptx |

“保存至任务目录”表示归属于本任务，不允许把逐图图片、提示词或复现清单散放在任务根目录。用户明确指定其他组织方式时遵循用户要求。

交付前逐项检查：索引中的全部已生成文件存在于对应子目录；图片、提示词、清单数量与已确认图数一致；任务根目录没有散落的逐图文件；视频占位不生成空PNG、提示词或清单。目录结构和路径检查通过后才能声明交付完成。

用户要求整理已有任务时，仅移动文件，不自动重命名或改变内容。移动前核实源与目标的绝对路径、归属、重名冲突及SHA-256；移动后核对数量、哈希并同步索引、当前状态、清单和交接的有效引用。历史生成记录和实际提交提示词中的原始路径属于执行证据，不全局替换；以追加迁移记录说明旧路径与当前路径。保持已嵌入PPT的媒体和成品不变。

## 状态、索引与清理边界
规划阶段只检查当前提示词及索引，图片/清单路径标预定，不能要求文件提前存在。生成阶段按已生成/已核对条目检查，未生成项不计为已交付。宣布整套生成交付完成前，所有非占位图都须有最终图、当前提示词、逐图清单及对应状态。
唯一索引表头每列只能出现一次，每行列数必须与表头一致；更新时按字段名修改，禁止重复追加哈希列或依赖未经检查的固定列偏移。索引文件写入后回读并验证，不以程序退出码替代表格完整性。
清理仅针对本轮创建、已验收且不再被当前状态/索引/交接引用的可再生临时预览。仍用于恢复进度的运行状态、失败诊断、返工原图和已有PPT不得一并删除；若需精简活动状态文件，先迁移有效引用并验证可继续恢复。原始输入、参考素材、当前提示词、最终图片和清单不属于可清理临时文件。
第四阶段只读上游任务包，不要求迁移历史目录；按其公共技能另行组织复现产物。
交付前运行本目录下的[只读目录与索引校验器](../scripts/validate_task.py)：`python validate_task.py 任务目录 --phase plan`用于规划交付，`--phase generated`用于整套生图交付。脚本检查文件、哈希与索引结构，不代替技术内容或真实渲染验收。
