# 可编辑教学图

面向教师的四阶段Codex技能包：**PPT规划 → 教学图生成 → 模板嵌图展示 → 对象级可编辑复刻**。第三、四阶段按需执行；只生成图片也能完成任务。

## 口令与完整提示词两种入口

已安装且当前聊天能发现四个技能时，在明确的教学图任务中可以直接说：

| 口令 | 调用 | 工作 |
|---|---|---|
| 执行第一步 | `$teach-1-plan` | 分析PPT并给拆分方案；确认数量、标题与名称后保存完整提示词 |
| 执行第二步 | `$teach-2-gen` | 读取确认的完整提示词，生成尚未完成的教学图 |
| 执行第三步 | `$teach-3-embed` | 按模板合成展示版PPT |
| 执行第四步 | `$teach-4-ppt` | 忠实重建对象级可编辑PPT |

口令仅在教学图流程明确时采用上述含义；其他项目里的“第一步”不能被强行解释为教学图任务。任务或阶段不明时先询问，输入不足时集中问答并等待。已经确认的任务、路径、名称和选择自动沿用，阶段授权分别执行。

也支持完整复制提示词：需要检查全部规则、跨环境使用或未安装这四个技能时，复制下面对应的完整Prompt正文代码块，保留全部适用规范；资料与必要选择通过问答补全，不要求先手改占位符。完整Prompt不替代生图、PPT读写/渲染和对象级复刻工具依赖。

- [09：PPT分析、确认与完整提示词保存](https://github.com/zcq19991029/codex-prompt-series/blob/master/prompts/09-PPT拆解与教学信息图生图规划-直接复制.md)
- [08：完整生图规范及对象级复刻Prompt](https://github.com/zcq19991029/codex-prompt-series/blob/master/prompts/08-通用教学信息图与可编辑PPT复现-直接复制.md)
- [10：完整模板嵌图Prompt](https://github.com/zcq19991029/codex-prompt-series/blob/master/prompts/10-教学图模板嵌入与PPT合成-直接复制.md)

每张图的完整版提示词仍以UTF-8保存在任务目录“提示词/”，按页序和标题命名，每图仅一份当前文件，索引记录路径和版本。需要全量展示时可说“显示当前任务全部完整提示词供我复制”：逐图读取当前文件、按索引输出完整正文，不以摘要或“同上”代替；正文过长时按完整文件边界分批并标明剩余页号，不截断或压缩规范。展示提示词不等于授权生图、嵌图或复刻。

## 1. 先选需要的结果

| 阶段 | 技能 | 输入 | 交付 | 聊天安排 |
|---|---|---|---|---|
| 1 规划 | `$teach-1-plan` | 教学PPT、保留项 | 数量与拆分方案；确认后保存完整提示词 | 第一个聊天 |
| 2 生图 | `$teach-2-gen` | 确认规划、当前提示词 | 图片、总索引、复现清单与交接 | 继续同一聊天 |
| 3 模板合成 | `$teach-3-embed` | 确定图片、索引、PPT模板 | 可直接上课的嵌图展示版PPT | 同一聊天，按需调用 |
| 4 可编辑复刻 | `$teach-4-ppt` | 确定图片、清单、交接、可选模板 | 对象级可编辑PPT及必要验收资料 | 新聊天，按需调用 |

第三阶段的标题和模板对象可编辑，图内内容仍是图片。第四阶段把普通文字、代码、卡片、表格和连接线重建为原生对象，复杂插图可保留为独立图片；验收报告说明编辑范围与差异。

```text
已有同名入口时先核对原件、链接及自定义内容，不覆盖或重复安装。
旧teach-3-ppt现为teach-4-ppt，按升级授权迁移旧入口；不要删除链接后端原件。
```

也可克隆本仓库，在自己的教学项目`.agents/skills/`中链接到四个完整技能目录。Windows用Junction，macOS/Linux用符号链接，不用`.lnk`。用户级安装与项目链接择一维护，换电脑需重建链接。

安装后检查当前聊天能否发现技能；未出现时重开聊天或重启Codex。实际安装目录以环境为准，常见为`$CODEX_HOME/skills`或`~/.codex/skills`。发现成功不等于后端能力已就绪。[Codex技能文档](https://developers.openai.com/codex/skills/)。

## 3. 按顺序调用

各阶段代码块可直接复制，无需预填占位符。同一聊天承接当前任务；新聊天从当前项目或提供的任务包定位，出现多候选或缺少信息时集中提问并等待回答。结构化问答依环境可用工具，不要求先手动切换计划模式。

先创建一个教学主题项目，将任务资料保存在项目内。规划和生图在同一聊天完成；复刻另开聊天。主题项目根目录只维护共用AGENTS，生图和复现各自维护README与项目交接，不为普通素材目录新建说明。

### 第一步：上传PPT，只确认拆分方案

```text
用 $teach-1-plan 分析这份PPT。
报告实际页数与检查范围，先只给建议图数量、标题、拆分理由和原页覆盖映射。
检查视频媒体对象及外链，确认视频页整页跳过生图，保留来源页和输出页序号；疑似页先指出。
先不写完整提示词，不生图；让我确认数量、增减和标题，并询问任务文件夹名称。
```

PPT页数、生成图片数与最终PPT页数分别报告；一页可拆多图，多页也可合一图。实质知识、练习和保留素材不能静默遗漏。没有输入PPT时等待上传，不自行选旧文件。

### 第二步：确认方案、保存提示词，再授权生图

先发送：

```text
确认当前数量、标题和拆分方案。沿用我已提供的任务文件夹名称；尚未命名时询问名称并等待我输入。
用 $teach-1-plan 编写每图完整版提示词并以UTF-8保存。
新任务按确认输出页序命名P01-标题-提示词.md，保存生图规划.md及唯一提示词索引.md。
视频占位没有提示词或图片文件，编号保留；每图仅一份当前提示词。
回读核对后给我索引、文件路径与概览，此时先不生图。
```

提示词检查后，再发送：

```text
生成。用 $teach-2-gen 继续当前已确认任务；沿用我已指定的范围，未指定则生成全部尚未完成的已确认图，不重生成已通过图。
逐张读取完整提示词及参考素材，使用完整正文调用生图工具；保存核对后再处理下一张。
视频占位跳过，图片保存为P01-标题.png等已确认名称，不压缩页号。
记录实际提交提示词哈希、选定图片哈希、真实尺寸、模型标识和核对状态。
更新唯一索引、生成记录、逐图复现清单及复现交接；不重复建立对应总表。
本次只授权图片生成，不自动合成PPT或复刻。
完成后给我填好真实路径的后续调用语句，未决定的输出选项在后续调用中通过提问让我选择。
```

确认规划不等于授权生图；已有“保存后自动生成”的明确授权时继续执行，不逐图重复求许可。生图按当前完整文件执行，不用聊天摘要重写输入。默认主体目标1814×867、白底、无总标题栏；实际尺寸如实报告，不裁切或拉伸。

PPT提供教学内容依据，生图可创新构图、原创插图和通俗表达；原页无插图也生成。只有用户锁定原样保留的素材才忠实复用，关键数字、代码、公式、条件及逻辑关系仍须准确。原创设备或作品标为示意，不冒充真实成果。

生成前核对执行时官方模型信息与工具实际能力；不硬编码“最新”型号。工具不暴露底层版本时注明未核实，不能承诺最新版本已选中；无法满足明确模型要求时说明并让用户选择可用方案，不自行切换收费API。

### 第三步：按模板合成展示版PPT（可选）

```text
用 $teach-3-embed 合成当前任务的确定版本教学图。
自动从当前聊天、任务索引及实际文件读取任务目录、完整页序、标题和确定图片；不让我手填这些路径。
优先使用我已指定的模板，否则检查生图子项目的共享“嵌图模板.pptx”；输出到图片任务根目录，命名为任务名-嵌图版.pptx，保留已有成品。
缺少必要资料、存在多个任务或模板候选时，集中询问并等待我选择或输入；能确定的字段自行补全，不重复问已确认项。
按完整输出页序放图和填写标题；视频位置保留模板空主体区及页号，不插视频或内容标题。
图片整幅等比、底端对齐，保护横线和页眉，不裁切拉伸；比例造成的小间隙如实报告。
检查全部页面，结论写生成记录，成功后清理本次临时预览和操作文件。
保留原图、模板和已有成品，本次只合成展示版，不做对象级复刻。
```

共享模板默认放`生图/嵌图模板.pptx`，展示PPT放图片任务文件夹。几何比例造成的小间隙如实记录；多页模板要明确重复页和封面/结束页。默认只交付PPT，用户可直接打开查看，仍须完成实际渲染检查。

### 第四步：在新聊天复刻可编辑PPT（可选）

下面的调用可直接复制。智能体先从当前项目或任务包定位交接与索引，只有无法确定任务、资料或实质选择时才询问并等待回答。

```text
用 $teach-4-ppt 忠实复刻确定版本教学图，制作对象级可编辑PPT。
先在当前项目或我提供的任务包中定位复现交接.md及唯一提示词索引.md，自动读取原图、逐图清单、必要素材、模板、已有展示版和生成记录，不让我逐项手填路径。
没有明确任务、出现多个候选或缺少必要文件时，集中询问并等待我选择或提供位置，不自行挑选旧任务。
沿用已确认范围和输出选择；若尚未选择合并或分别输出，给出选项让我选择。输出默认放复现子项目下的同名任务目录，合并文件名为任务名-可编辑版.pptx；保留已有成品。
先核对实际文件、图片版本和标题对应。最终原图决定布局与插图，清单校对准确文字、数字及关系；冲突先指出并等待解决。
普通文字、代码、表格、卡片和连线重建为原生对象，复杂插图可忠实分离为独立图片；禁止整图铺底覆盖文字的伪可编辑。
保持源图比例，按已选模板主体区放置；模板未确定时展示可用选项供我选择，不猜用旧模板。
合并时按完整页序保留视频空白主体区和页号；仅复刻有原图的图页，不对视频占位运行OCR或生图。
输出仅写复现任务目录，保留生图原图与展示版。按当前公共image-to-editable-ppt技能完成验收，说明编辑范围及差异。
本次只做忠实复刻，不重新策划或生图；无需读取规划聊天历史。
```

生图完成时应提供已填真实路径的调用语句。第三阶段可跳过，直接用第二阶段确定PNG复刻。复杂插图“无额外素材”不妨碍从最终PNG提取。换电脑时迁移完整任务包并修正路径，只复制交接文件不足以执行。

```text
│   ├── 嵌图模板.pptx               按需提供的共享模板
│   └── 用户命名的任务文件夹/

│       ├── 复现清单/               P01-标题-复现清单.md
│       ├── 生图规划.md              数量、拆分理由及原页覆盖
│       ├── 提示词索引.md            唯一总表：页序、标题、路径、版本
│       ├── 生成记录.md              生成、修订和嵌图检查结论
│       ├── 复现交接.md              引用总表，补充复刻约束
│       └── 任务名-嵌图版.pptx       第三阶段完成后才生成

        └── 必要验收及运行资料       遵循公共复刻技能
```

### 文件编号

唯一索引分别记录**来源PPT页码、教学图编号、最终输出页序号**。新任务使用输出页序前缀，与确认标题共同命名：

| 文件 | 示例 |
|---|---|
| 图片 | P01-按键消抖原理.png |
| 当前提示词 | P01-按键消抖原理-提示词.md |
| 复现清单 | P01-按键消抖原理-复现清单.md |
| 分别复刻PPT | P01-按键消抖原理.pptx |

旧任务沿用已确定路径，不自动批量改名。重复标题、非法字符、文件冲突先解决，不覆盖已有成品。页序调整同步关联路径，并标受影响旧PPT待更新。

### 视频页

检查PPT媒体结构、视频关系及外链，结合实际页面判断；只有封面图、播放按钮或失效链接时标疑似，不保证全部自动识别或已验证可播放。不播放、转录、下载或提取视频帧。

确认的视频页整页跳过，即使同页有文字也不擅自拆图。索引类型为“视频占位”，状态为“跳过生图”，素材路径记“—”。视频页占最终页号，无空提示词、占位PNG或复现清单文件。例如P02为视频页，下一张图使用P03。

合并PPT时保留视频位置的空白主体及页号，视频由用户自行补入。复刻只派发有原图的图页，空视频页不送OCR或重建；分别输出单图PPT时只在索引与交接保留视频位置，不另造空PPT。

## 5. 文件用途、返工与验收

| 资料 | 唯一用途 |
|---|---|
| 生图规划.md | 数量、拆分理由、保留项及来源覆盖 |
| 提示词索引.md | 页序、标题、全部路径、尺寸、哈希及状态的唯一总表 |
| 生成记录.md | 实际提交输入、修订历史、检查结论及已知偏差 |
| 逐图复现清单 | 准确文字、数字、公式、关系和最终图实际输出描述 |
| 复现交接.md | 引用索引，补充独立素材、模板、输出选择及复刻约束 |

每图只保留一份当前提示词；修订更新原文件，历史提交哈希留在生成记录。当前提示词修订不代表旧图片已同步；图片或模板更换也不代表已有PPT已更新。索引锁定最终图片哈希，记录受影响成品待更新，重做时另存并重新验收。输入PPT哈希记于规划，模板与输出PPT哈希记于生成记录。

复刻以最终图确定布局与插图，以清单核对准确内容；清单、原图或显式要求冲突时明确解决，不静默改写。第三阶段不创建重复检查报告，检查成功后清理本次临时预览、截图及JSON；失败时保留必要证据。原始输入、参考素材、原图、当前提示词、清单和已有PPT保留。

结构、内容、实际渲染和打开检查分别记录，未做的标未验证。第四阶段遵循公共复刻技能的验收与运行文件要求，不能为了精简而删除必需材料。

## 必要问答的等待规则

异步提问后保持当前轮次等待，收到真实选择或输入才继续；不能发出问题就以最终答复结束。每次等待不超过60秒，超时继续等待，不默认选择、不重复发题。用户取消或暂停时停止等待。仅有文字问答且没有等待机制的环境须明确说明由下一条消息恢复，不作持续等待承诺。

每个教学图阶段完成后先报告结果，再主动询问下一步并等待选择；允许停止或结束。已明确授权连续执行的范围不重复确认，未授权阶段不自动启动。
